## 4. 契约、身份与数据约束

### 4.1 API 基线

- 保留现有 operationId 与 `173 paths / 198 operations` 的全局统计；CH-028 本地契约实测为 `173 paths / 198 operations / 198 unique operationId / 327 schemas / 714 schema refs / 2,734 local refs / 0 dangling refs`，Redocly 0 warning。B13 实现现有 Agent `21 paths / 23 operations` 及配套 Admin operation，不新增重复 operationId；完整 operation manifest SHA-256 为 `128509f76f2e62ebe78cd0465205a94236f87f70904bf614664dd1b02548dc80`，generated contracts 两次生成稳定为 `c4f3ef3759e277a43ffa7780009e028eb5cdb08b3d56d5d54e3b0bdbb720940b`。该本地证据不替代 B13.0 的远端退出门禁。
- `/agent/**` 使用独立 Bearer realm：`aud=qingxu-agent-web`、`role=AGENT_ADMIN`、`assurance=PASSWORD`。Store、Admin、Agent token 必须交叉拒绝；临时会话固定 `CHANGE_PASSWORD_ONLY` 且无 refresh。
- B13.0 配置固定覆盖 `AGENT_AUTH_TOKEN_AUDIENCE`、Agent access/session TTL 与登录限流、`STORE_PROMOTION_PUBLIC_BASE_URL`、既有 `FIELD_ENCRYPTION_*` 字段加密环，以及用途隔离的 `BANK_ACCOUNT_HASH_*` 当前/历史 HMAC key ring；不同用途密钥不得复用。
- 新增专用 `AgentSessionResponse`、`RestrictedAgentSessionResponse`、`AgentCurrentResponse`；当前账号仅返回代理 ID、编号、名称、状态和授权模式，不返回秘密或未授权经营数据。
- 创建代理、重置密码、轮换邀请码的首次响应携带 `disclosure_state` 并只披露一次秘密；幂等重放返回脱敏资源和重新签发指引，不保存或再次披露秘密。
- `/agent/products` 删除可请求非 ACTIVE 状态的筛选参数，服务端固定只返回已上架且当前授权的 ACTIVE 商品；白名单只限制推广可见性，不污染历史客户绑定和已冻结佣金。

### 4.2 推广与归属

- 推广链接使用 `STORE_PROMOTION_PUBLIC_BASE_URL` 生成，邀请码须有效、未过期且属于 ACTIVE 代理；禁用代理不得创建新绑定。
- QR 由服务端生成，不经客户端 upload/complete；推广素材与 `READY/PRIVATE/PROMOTION_QR` 文件原子绑定，创建响应仅返回结构化文件事实，不直接返回签名 URL。下载必须通过唯一受控的 Agent Files 例外重新鉴权，且只允许当前 Agent 读取本人 `promotion_asset.qr_file_id` 绑定文件。撤权、下架或邀请码失效后，旧链接安全退化，不删除历史归属和佣金事实。
- 客户转移、转直营与支付归因均由服务端在锁内复核；当前代理只能读取当前绑定客户，历史已支付订单使用支付时归属快照。

### 4.3 佣金、钱包与提现

- 平台/分类/SKU 规则按 `SKU > 分类 > 平台` 继承；`null` 表示继承，`0` 表示明确零佣金。规则只追加版本，不回写历史支付快照。
- 预计佣金、已入账佣金、退款冲正和钱包余额均由服务端投影；佣金流水、余额流水、审计和 Outbox 与业务事实同事务提交。
- 冻结提现固定为 `available=-amount/frozen=+amount`，拒绝为 `available=+amount/frozen=-amount`，支付为 `available=0/frozen=-amount`。统一锁 Agent Wallet，幂等提交只能产生一个进行中申请。
- 所有资金命令复用 B10-B12 的稳定锁序并统一锁 Agent Wallet；幂等、审计和 Outbox 必须与余额、佣金或提现业务事实在同一事务提交。
- 银行账号去除 ASCII 空格和连字符后须为 6-32 位数字。只保存 AES-GCM 密文、用途隔离 HMAC、末四位和 key ID；常规接口、日志、审计、Outbox、幂等响应和前端持久化永不返回明文。
- 银行卡完整查看仅允许已认证 SUPER_ADMIN 通过 60 秒 TOTP reauth、单次授权和固定用途访问；五次失败必须锁定。离页、复制、超时或失败均清除敏感值并写最小审计。

### 4.4 `0006_b13_agent_finance_guards`

`0006` 为前向、可回放、失败原子化的防护迁移，不新增业务表或枚举。迁移前必须执行历史预检，异常不得自动修复。至少覆盖：

1. AgentProfile 与 `AGENT_ADMIN` 角色一致性、代理状态和版本包络。
2. 邀请码生命周期、代理归属和推广目标的主体包络。
3. 提现状态字段组合、金额边界、银行卡快照不可变性和 PAID 凭证要求。
4. 佣金规则版本、佣金流水、钱包流水与订单/订单项支付快照的引用形状。

空库回放、`0005 -> 0006` 升级、runtime 权限、函数/触发器指纹和 `migration diff=0` 均为 B13.0 强制门禁；已有 `0001` 至 `0005` 必须逐字节不变。
