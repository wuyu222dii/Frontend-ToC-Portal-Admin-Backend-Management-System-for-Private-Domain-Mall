## 状态

- 当前批次：B19.0-B19.4 development 实施中。
- 基线：`v2.4.14 / 2.4.14-ch036`。
- staging/production：继续 `NO-GO`；B16/B17 独立环境、恢复和外部复核证据尚未闭合。

## 交付

- HR-15 在线安全重置仅允许当前管理员本人；预览不接收凭据，确认时条件接收 `new_password`。
- 密码/TOTP/双重重置原子递增账号版本并撤销全部会话、challenge、reauth grant 和旧 MFA 因子。
- 受控 `admin:offline-recovery` CLI 提供 `request`、`approve`、`reject`、`execute`；不提供 HTTP 全凭据恢复。
- 离线恢复要求两名不同、非目标、ACTIVE `SUPER_ADMIN`；新密码仅隐藏输入，数据库只保存哈希和凭据指纹。
- Admin 账户安全页复用现有会话清理，完成预览、确认和失效后重新登录。

- contracts lint/generate 无漂移；database、API、admin-web 构建通过。

- development smoke 验证本人限制、预览不含凭据、失败锁定、CLI 双人审批约束。
