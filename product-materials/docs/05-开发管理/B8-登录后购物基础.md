## 4. CH-018 冻结契约

### 4.1 版本、统计与数据库冻结

- 产品/PRD 基线：`v2.4.6 / CH-018`。
- OpenAPI 版本：`2.4.6-ch018`。
- 冻结统计：173 paths / 198 operations / 198 unique operationId / 323 schemas / 701 schema refs / 2,653 local refs / 0 dangling refs。
- 新增 `GET /store/favorites/{product_id}`；路径总数仍为 173。
- 新增 `FavoriteProductView`、`FavoriteStateResponse`、`CartMergeItemInput`。
- 以 `CartItemWriteRequest` 等量替换 `CartQuantityRequest`；请求必填 `quantity` 与 `selected`。
- 所有 Product、SKU、Address 路径参数统一使用 ULID 校验。
- Prisma、根目录与技术设计目录的两份 `0001_initial`、76 models / 59 enums 和冻结哈希必须逐字节不变；不新增 migration，`migration diff=0`。

### 4.2 收藏

- 收藏列表固定按 `created_at DESC,id DESC`；搜索只匹配 trim 后商品名称，大小写不敏感，长度 1-200。
- `FavoriteProductView.availability` 闭合为 `SALEABLE | OUT_OF_STOCK | UNAVAILABLE`。
- 商品失效后收藏仍可见，价格与图片允许为 null，`is_salable=false`；不得泄露管理字段。
- PUT 只允许当前公开商品；重复收藏返回成功且不产生重复记录。
- DELETE 在收藏不存在或商品失效时仍幂等成功。
- 单商品状态返回当前 CUSTOMER 对 `product_id` 的收藏布尔值，不把商品失效误报为未收藏。
- 所有收藏写使用 `HASH_ONLY`，不得缓存响应正文；重放必须重新鉴权并返回当前投影。

### 4.3 服务端购物车与游客合并

- 空购物车 GET 无数据库副作用，固定返回 `cart_id=null,items=[]`；首次写入或合并时才懒创建购物车。
- 删除无数据库来源的 `CartResponse.version` 与无法权威计算的 `change_flags`。
- 购物车项增加 `selected` 和可空 `primary_image_url`；状态闭合为 `SALEABLE | INSUFFICIENT_STOCK | OUT_OF_STOCK | INACTIVE | DELETED`。
- 合计只包含已选择且 `SALEABLE` 的项目；每项数量 1-99，购物车最多 100 个不同 SKU。
- PUT 使用 `{quantity,selected}`；GET 固定按 `created_at ASC,id ASC`。
- 合并请求最多 100 项，SKU 不得重复；数量按 99 封顶，选择状态采用 `existing OR incoming`。
- 合并事务全成全败；未知 SKU 阻断整个合并，已失效但仍存在的 SKU 可以保存并返回当前状态。
- 客户端使用本地展示快照与服务端最新投影比较变化，不为价格或库存快照新增数据库字段。
- 写事务使用 Serializable 和统一重试；锁序为幂等事实、客户、购物车、升序 SKU/购物车项、审计。
- 同一幂等键不得重复应用命令；无法安全重放时返回 409 并要求客户端刷新。

### 4.4 收货地址

- 手机号必须是 11 位 ASCII 数字。
- 收件人、省、市、区各 1-80 字符；详细地址 1-300 字符；所有文本 trim 后不得为空且不得包含控制字符。
- 手机号和详细地址使用 AES-256-GCM 加密，AAD 分别绑定 `customer_address:<id>:phone_ciphertext` 与 `customer_address:<id>:detail_ciphertext`。
- 手机哈希复用 Store 手机密钥环，但使用独立域 `qingxu:store-address-phone:v1`。
- 地址列表只返回脱敏摘要；详情、创建与更新只向当前地址所有者返回完整值；跨客户访问统一返回 404。
- PATCH/DELETE 必须携带 `If-Match`；版本冲突返回 409。
- 第一条地址自动成为默认地址；设置新默认地址时原默认地址原子清除。
- 删除默认地址后按 `created_at ASC,id ASC` 自动提升下一条；存在其他地址时，禁止将当前默认地址直接改为非默认。
- 审计只记录地址 ID、版本、状态和默认标志，严禁记录姓名、手机号或详细地址。

### 4.5 错误、缓存、限流与幂等

- 新增 `CART_ITEM_LIMIT_EXCEEDED`：HTTP 422。
- 新增 `DEFAULT_ADDRESS_REQUIRED`：HTTP 422。
- 所有 B8 个性化成功及 JSON 错误响应设置 `Cache-Control: no-store, private` 与 `Pragma: no-cache`。
- B8 登录接口共享 CUSTOMER 与来源 IP 组合的 Redis 固定窗口限流：每 60 秒 120 次。
- Redis 只保存域隔离 HMAC 摘要，不保存原始 IP 或客户标识；Redis 未就绪、断连或结果非法时必须 fail closed。
- 新增 `STORE_CUSTOMER_RATE_LIMIT_MAX=120` 与 `STORE_CUSTOMER_RATE_LIMIT_WINDOW_SECONDS=60` 环境契约。
- B8 写操作使用 `HASH_ONLY`，不得缓存响应正文；重放必须重新鉴权并返回当前投影，无法安全重放时返回 409。
- B8 写操作不产生异步副作用，不新增 Outbox 事件。
