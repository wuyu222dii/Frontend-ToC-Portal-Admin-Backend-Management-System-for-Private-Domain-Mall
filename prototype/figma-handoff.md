# 青序生活总部管理后台 · Figma 交付规范

## 1. 交付信息

- 原型版本：v1.5（CH-005）
- 设计日期：2026-08-11
- 目标终端：PC 管理后台
- 基准画板：1440 × 1024、1024 × 768
- 可交互参考：`prototype/admin.html`
- 技术映射：Vue 3 + Element Plus
- 使用角色：超级管理员（总部平台全部权限）
- 首期页面：登录、数据看板、商品、品牌、分类、Banner、库存、订单、售后、客户、代理、统一佣金规则、提现、业务规则与审计日志

本规范用于在 Figma 中重建设计源文件。HTML 原型提供完整视觉和交互参考，Figma 文件负责组件化、标注和评审流转，两者应保持相同命名和状态。

CH-005 以 22 个总部页面/关键视图为冻结契约：16 个 `.page-view`，加登录、发货弹层、售后工作流、代理抽屉、客户抽屉和银行卡本人 TOTP 查看。当前 v1.5 不新增页面，在原视图内补齐 SPU 库存汇总/SKU 下钻、验货证据封存与 typed 二阶段处置、代理六类目标下钻。所有详情、弹层和抽屉绑定当前选中记录。

## 4. Components

组件必须使用 Auto Layout，并为交互组件建立 Properties。

### 4.1 导航

`Navigation/Sidebar Item`

- Properties：`State = Default | Hover | Active`、`Badge = None | Number`、`Collapsed = True | False`。
- 展开尺寸 200 × 42，收窄尺寸 52 × 42。
- 图标 19 × 19；展开时图标与文字间距 12。
- Active 背景 `sidebar/active`，文字白色。

`Navigation/Topbar`

- 高度 64，包含导航收起按钮、面包屑、全局搜索、通知和账号入口。
- 全局搜索宽 246；1024 画板宽 210。

### 4.2 按钮与图标按钮

`Button/Default`

- Properties：`Type = Primary | Secondary | Ghost | Danger`、`Size = Small | Default`、`State = Default | Hover | Disabled`、`Icon = On | Off`。
- Default 高 36，Small 高 30；横向 padding 14/10，元素间距 7。
- Primary 仅用于当前页面最重要动作，例如新增商品、保存上架、确认发货、同意退款。

`Button/Icon`

- 34 × 34，图标 18；紧凑表格操作为 30 × 30。
- 熟悉图标直接使用：查看、编辑、删除、复制、关闭、返回、通知、菜单。
- 每个图标按钮在开发时必须有 `title` 或 Tooltip。

### 4.3 表单

建立 `Input/Text`、`Input/Search`、`Select/Default`、`Textarea/Default`、`Switch/Default`、`Checkbox/Default`。

- Default 高度 36，边框 `border/strong`，圆角 5。
- Focus 边框 `brand/default`，外环 2px、10% 品牌绿。
- 必填星号使用 `accent/default`。
- 错误信息紧邻字段下方，字号 12，使用 `danger/default`。
- 开关尺寸 34 × 19；开启时主色填充。

### 4.4 数据组件

`Data/Metric Card`

- 1440：四列等宽；1024：两列。
- 高度 140/124，内边距 18。
- 指标图标 36 × 36，圆角 7。

`Data/Table`

- 表头高 42，数据行高 64。
- 表头背景 `bg/subtle`，字号 10。
- 行 hover 背景 `#FBFCFB`。
- 操作列固定右侧；1024 隐藏标记为 Optional 的列。

`Data/Status Tag`

- 高 22，水平 padding 8。
- 状态映射：在售/已完成/已启用/已打款为绿，待发货/待退货为琥珀，运输中为蓝，退款售后/待审核为珊瑚，待退款/待打款为紫，草稿/下架/已停用为中性灰。
- `Rule Source Tag` 增加平台默认、一级分类、SKU 例外、SKU 明确 0% 四种状态；同时使用文字与语义色，不能只靠颜色区分。

### 4.5 反馈组件

- `Feedback/Toast`：最小宽 240，高 42，顶部居中 24，显示 2.2 秒。
- `Overlay/Modal`：常规宽 520，库存弹窗 450，售后审核 680。
- `Overlay/Drawer`：右侧宽 430，全高。
- 遮罩：`#0D1B15` 46%。
- 弹层打开后焦点进入首个输入框，Esc 和遮罩点击可关闭。

## 5. 页面规格

### 5.1 登录

- 1440 使用 58%/42% 双栏；1024 使用 52%/48%。
- 左侧为深绿品牌区：品牌标志、产品包装陈列、品牌文案；右侧为账号密码表单。
- 账号和密码默认均为空；原型不展示、预填或提示任何正确值，提交交由模拟服务端按格式和账号状态校验。
- 登录按钮连接 `Admin/Dashboard/Default`；空字段、错误凭据、停用账号和连续 5 次失败锁定 15 分钟分别进入对应错误状态。
- 密码查看按钮切换文本可见状态。

### 5.2 数据看板

- 顶部为页面标题、日报/月报切换、对应的 `date`/`month` 选择器和查询按钮；切换周期时保留各自最近一次选择。
- 查询过程进入 Loading 并禁止重复提交；`2026-08-11` 日报为可验收空数据夹具，`2026-08-09` 日报首次请求为网络错误夹具，Retry 保留日期与日报筛选后成功加载。
- 待发货提醒横条占满内容宽，按钮进入待发货订单列表。
- 第一行四个指标：今日销售额、今日订单、客户总数、本月销售额。
- 增加累计总销售额、当期净销售额和当期退款摘要；切换报表后按对应口径更新。
- 增加代理归属销售、活跃代理、新增绑定和待审核提现四个经营指标；每项为可点击入口，分别进入代理、客户或带“待审核”筛选的提现列表，活跃代理入口携带“本期活跃”筛选（区间内存在有效归属订单），不得用账号“已启用”代替活跃口径。
- 第二行左侧销售趋势，右侧商品销量排行；趋势支持 7 天/30 天切换。
- 排行榜支持商品销量/客户消费切换，客户榜按有效净消费额排序。
- 第三行四个订单任务入口：待付款、待发货、运输中、待审售后。
- 底部为最新订单表，订单号和查看按钮进入订单详情。

### 5.3 商品列表

- 顶部主动作仅保留“新增商品”。
- 状态 Tab：全部、在售、已下架、草稿。
- 筛选器：关键词、一级分类、品牌、状态、重置。
- 表格字段：商品、零售价、SKU 数及实物/锁定/可售汇总、销量、状态、首页推荐、操作。
- 点击库存摘要下钻当前 SPU 的全部 SKU；选择器每次切换必须重绑表单与流水，保存只更新所选 SKU 并回写 SPU 汇总。
- 筛选无结果时显示空状态，不改变表格容器高度。

### 5.4 商品编辑与 SKU

- 页面采用主内容 + 260px 发布侧栏；1024 侧栏收窄至 230。
- Tab：基本信息、规格与库存、详情内容。
- 基本信息：图片、商品名称、品牌、货号、一级分类、商品卖点。
- SKU：规格名称、规格编码、零售价、可售库存、有效佣金、规则来源、删除；至少保留一个规格。
- 有效佣金只读展示解析结果和预计单件佣金；SKU 例外编辑统一进入佣金规则页，不在商品编辑页创建第二套规则入口。
- 详情内容：商品介绍、成分说明、使用方法，可新增图文模块。
- 发布侧栏：商品状态、首页推荐、新品标记、库存与销量摘要。
- 保存并上架后 Toast 反馈并返回商品列表。

### 5.4A 品牌、分类、Banner 与库存

- 品牌页维护品牌编码、故事完整度、关联商品、排序和软停用状态；历史商品与订单快照不删除。
- 分类页覆盖 8 个首期一级分类并支持新增；存在在售商品时禁止停用，须先迁移或下架关联商品。
- Banner 页展示顺序、真实投放内容、时间范围、跳转目标和启停状态；首页顺序使用稳定编号。
- 库存页以 SKU 为最小单位，同时展示可售、支付预占、售后占用、可发货、预警值和库存状态。
- 可发货数量按 `可售 - 支付预占 - 售后占用` 展示；待处理售后数量不得进入发货单。
- 品牌、分类和 Banner 的新增/编辑须完成必填与冲突校验，保存后写回当前行；归档为软删除并保留历史引用，不能仅显示成功 Toast。
- 库存调整绑定当前 SKU，要求调整原因和备注，提交后同步余额、预警并追加库存流水；“查看流水”展示同一 SKU 的只追加记录。

### 5.5 订单列表与详情

- 订单状态入口：全部、待付款、待发货、运输中、已完成、退款售后。
- 筛选器：订单号/客户/手机号、状态、日期范围、重置。
- 待发货订单显示“发货”文本动作；所有订单可进入详情。
- 详情顶部为 5 步状态条：提交、付款、待发货、运输中、完成。
- 主栏展示商品与金额、订单记录；侧栏展示收货信息、订单信息、操作按钮。
- 每个订单商品行展示支付时净商品额、有效比例、规则来源和佣金金额；混合订单逐行核算后汇总，侧栏展示规则版本。
- 订单详情、发货弹窗、收货信息和佣金快照必须绑定当前选中订单；切换记录不得残留上一笔静态样例。
- 当前 MVP 不支持消费者订单留言；详情只保留总部内部备注入口，不得构造或展示消费者留言字段。
- 发货弹窗列出本次包裹的全部可发订单项、数量、物流公司、物流单号、首条物流事件和是否通知客户。任一订单项存在活动售后占用时，单包裹 MVP 阻断整单创建包裹。
- 发货弹窗的“取消”只表示在创建前放弃本次操作；包裹创建后不提供取消包裹或替换包裹动作。提交成功后订单进入运输中、发货入口隐藏、物流事件和状态条同步更新。

### 5.6 售后审核

- 顶部四项摘要：待审核、待退货、待退款、本月售后率。
- 筛选器：售后单/订单/客户、类型、状态、重置。
- 审核弹窗绑定当前售后单，展示售后类型、订单项、申请数量/金额、原因、客户说明、凭证和货物状态。
- 售后申请创建时占用可退数量和金额，弹窗明确显示占用；待处理数量禁止发货。
- 工作流覆盖审核、退货地址、客户退货物流、总部验货、验货异常人工复核、部分/全额退款、回库、佣金冲正和 `REFUND_FAILED` 重试；不同状态只显示当前允许动作。
- `WAITING_INSPECTION` 弹窗绑定当前售后项，录入 `received_qty`、`approved_refund_qty`、`restock`、`damaged`、`scrap` 和 `return_to_customer`，并实时展示处置数量守恒结果。
- `PASS` 必须强制全量实收、全额批准且 `return_to_customer = 0`；所有结果（含 `ABNORMAL`）必须同时满足 `approved_refund_qty + return_to_customer = received_qty` 与 `approved_refund_qty = restock + damaged + scrap`，不存在“总部留货但不退款”的隐式状态，任一等式不成立不得进入二次确认。
- `PASS` 允许零证据；`ABNORMAL` 至少一份证据。提交后封存文件 ID、名称、摘要、验货人和时间，不再提供增删或重写入口。
- `ABNORMAL` 进入 `RETURN_EXCEPTION`，二阶段仅可一次选择 `CONTINUE_REFUND` 或 `REJECT_AFTER_RETURN`；两分支均原因必填，且不改写首次验货数量与证据。
- 验货影响预览必须展示实收、批准退款、回库、损坏、报废和退客数量；完成后按批准额度退款与冲正，只将 `restock` 数量追加库存流水。
- 拒绝、退款、金额补偿和退款重试必须填写原因，经影响预览与二次确认后执行，不要求 TOTP；驳回释放占用，退款失败保留占用供重试。
- 未发货退款成功自动回补对应 SKU；全额退款终止履约，佣金通过独立 `CANCELLED` 或 `REFUND_DEBIT` 流水处理。

### 5.7 客户列表与详情

- 摘要指标：客户总数、本月新增、复购客户、人均净消费。
- 搜索字段：微信昵称、姓名、手机号。
- 表格字段：客户、净消费额、消费次数、客单价、最近购买、注册时间、操作。
- 查看按钮打开 430px 右侧抽屉。
- 抽屉展示净消费额、消费次数、客单价、注册时间、最近访问、收货城市、手机号授权来源和最近购买商品，全部绑定当前客户。
- 账户手机号独立、可空且来自客户自愿授权；未授权显示“手机号未绑定”，不得从收货地址提取。
- 增加“服务归属”区块；只有超级管理员可调整。
- 归属调整必须填写原因、展示影响范围并勾选确认；只影响后续订单，结果写入审计日志。
- 归属状态保存在单个客户记录中；切换客户时必须重新读取，不共用抽屉临时状态。
- 转为平台直接客户时，同步更新状态、调整时间和代理归属计数。

### 5.8 代理管理

- 摘要指标：启用代理、已归属客户、本月归属销售、待结算佣金。
- 表格字段：代理名称与账号、规则适用、邀请码、归属客户、归属销售、可提现余额、状态、操作。
- 新增时生成邀请码与临时密码，首次登录需强制修改密码。
- 创建成功后一次性显示账号和临时密码，支持分别复制；关闭后不可再次查看。
- 商品授权默认为“全部在售商品”，可改为“自定义白名单”并从配置入口选择商品；详情展示模式和授权数量。
- 商品白名单只限制代理可查看和生成推广素材；已有绑定客户购买全店任意 SKU 仍按统一商品规则计佣。
- 新增、编辑与详情均不出现代理个人比例；统一展示“所有一级代理共用商品佣金规则”并提供规则页入口。
- 停用后禁止登录、新客户绑定与新佣金，历史订单、账务流水与已申请提现仍保留。
- 停用、启用或在编辑弹窗中变更状态均须填写原因、展示影响范围、二次确认并生成审计记录。
- 详情抽屉可查看归属客户、销售和钱包摘要；白名单选择写回当前代理并明确“不影响已有绑定客户全店计佣”。
- 邀请码支持复制、轮换、停用和有效期展示；轮换后旧码立即失效，已有绑定不受影响。密码重置撤销现有会话，并只在结果弹层一次性生成、复制运行时临时凭据，关闭即清除。
- 钱包分项展示可提现、申请冻结和负余额，并提供不可变佣金审计流水入口；流水按商品行展示混合比例、规则来源和版本。

### 5.9 统一佣金规则（ADM-22）

- 页面入口位于“渠道与结算”，直达状态为 `admin.html?autologin=1&view=commission-rules`。
- 页面顶部固定展示规则优先级：`SKU 例外 > 一级分类默认 > 平台默认`；一套规则适用于全部一级代理，不提供代理与 SKU 的独立配置矩阵。
- 摘要指标：平台默认比例、一级分类规则数、SKU 例外数、适用范围；右上展示当前规则版本。
- 分类规则表字段：一级分类、商品/SKU 数、分类比例、规则来源、SKU 例外数、最近更新、操作；首期覆盖护肤品、洗发水、沐浴露、防晒产品、香水、彩妆、男士护理、家庭清洁。
- SKU 表展示全部 SKU，不只展示例外；支持商品名/SKU 编码搜索与一级分类筛选，并区分继承分类、普通例外和明确 0%。
- 编辑弹窗统一服务平台、分类与 SKU：分类可选择“单独设置/继续继承平台”，SKU 可选择“单独设置/继续继承分类”，平台默认只能单独设置。
- `未设置/继续继承` 与 `明确 0%` 必须视觉、文案双重区分；0% 使用“明确不计佣”，不得显示为未配置。
- 弹窗实时展示有效比例、规则来源、SKU 预计单件佣金、预计影响商品/SKU 范围，以及保存后生成的新版本号。
- 新建例外、自定义比例、明确 0% 与恢复继承均进入同一编辑弹窗；保存必须填写原因、核对影响并勾选确认，成功后生成新版本与审计记录。
- 支付时快照包含规则版本、来源、一级分类、商品、SKU、比例、净商品实付额和佣金金额；退款按原商品行快照冲减，累计不得超过原佣金。

### 5.10 提现审核

- 摘要指标：待审核、已审核待打款、本月已打款、异常余额。
- 表格字段：申请单、代理、提现金额、脱敏收款账户、状态、申请时间、操作。
- 待审核“通过”不要求原因，但必须展示金额影响并二次确认；“拒绝”必须填写原因、展示金额影响并二次确认，冻结金额按负余额优先规则返回钱包。
- 通过后进入待打款；“标记已打款”必须先提供线下银行转账凭证，再展示不可回退影响并二次确认，不要求原因。
- 银行卡仅显示后四位；原型不实施真实文件上传或自动打款。
- 完整卡号入口只在内部状态 `APPROVED`（界面“待打款”）出现；仅要求当前管理员本人的 TOTP，不要求当前密码或恢复码。授权绑定当前管理员和提现单，仅使用一次并在 60 秒或离页时清除。
- 二次验证连续失败 5 次锁定 15 分钟；Error、Locked、Success 均独立成画板并写入安全审计。
- 拒绝时冻结额返回可提现并优先抵扣负余额；已打款时扣减冻结额，两者均同步钱包分项。

### 5.11 业务规则、审计与系统状态

- 业务规则页集中展示支付超时、迟到支付退款、未发货回库、售后占用、商品白名单、手机号和账号删除规则版本；支付超时固定为 30 分钟并以只读标签展示，不提供配置入口，首期仅最低提现金额和售后申请期可生成新版本。
- 审计日志只追加，字段包括时间、编号、事件、操作人、目标、原因、结果、客户端与状态。
- 高风险操作统一使用影响范围、确认勾选和成功审计反馈，不允许仅依赖 Toast 完成确认；原因按操作矩阵动态必填：退款/金额补偿/重试与拒绝类必填，提现通过和标记已打款不填，标记已打款另要求凭证，完整卡号另要求本人 TOTP。
- 通用反馈建立 Loading、网络 Error、403 权限不足、409 版本冲突和 Success 五种组件状态。

### 5.12 小程序服务代理联动

- 参考画板：`prototype/index.html?screen=service-agent&device=375`；未绑定邀请确认使用 `&binding=unbound&invite=QX-A1038`。
- 个人中心展示服务代理名称、所在城市和已绑定状态，不展示佣金。
- 通过有效邀请入口登录后，弹出一次性显式确认；说明价格、支付、发货和售后仍由平台统一保障。
- 绑定后不提供自助更换入口，异常归属引导联系平台客服。
- 邀请码先通过有效码映射校验；仅未绑定用户可确认，已绑定用户访问新邀请时保留原归属。

## 6. Prototype 连线

在 `04 Prototype Flows` 建立以下 Flow Starting Point：

### Flow A · 登录与导航

`Login/Default` → 点击登录 → `Dashboard/Default` → 点击左侧导航 → 对应列表页。

### Flow B · 商品维护

`Products/List` → 新增/编辑 → `Products/Edit-Basic` → SKU Tab → `Products/Edit-SKU` → 保存并上架 → `Products/List`。

库存分支：`Products/List` → 点击 SPU 库存摘要 → `Products/Stock-Modal` → 选择 SKU → 确认 → 回列表并重新汇总。

### Flow C · 订单发货

`Dashboard/Default` → 待发货提醒 → `Orders/List-ToShip` → 发货/查看 → `Orders/Detail` → 立即发货 → `Orders/Shipping-Modal` → 确认发货 → `Orders/Shipped`。

### Flow D · 售后审核

`AfterSales/List` → 审核 → `AfterSales/Review-Modal` → 退货地址/物流 → 录入六项数量和证据 → `PASS` 封存后退款，或 `ABNORMAL` 封存后进入 `RETURN_EXCEPTION` → 原因必填的 `CONTINUE_REFUND / REJECT_AFTER_RETURN` 二选一。

### Flow E · 客户查看

`Customers/List` → 查看 → `Customers/Detail-Drawer` → 查看订单 → `Orders/List`。

归属分支：`Customers/Detail-Drawer` → 调整归属 → `Customers/Attribution-Modal` → 确认 → 更新后续归属并显示 Toast。

### Flow F · 代理账号管理

`Agents/List` → 新增 → `Agents/Create-Modal` → 保存 → 生成邀请码和临时密码。

维护分支：`Agents/List` 补充 created_at → `Agents/Detail-Drawer` 以当前 agentId 切换客户/已付订单/佣金/钱包/提现/目标审计六类下钻；任意切换不得混入其他代理记录。

佣金入口：`Agents/List` 或 `Agents/Detail-Drawer` → `CommissionRules/Category-Default`，不经过代理个人比例编辑。

### Flow G · 统一佣金规则

`CommissionRules/Category-Default` → 编辑分类 → `CommissionRules/Edit-Category` → 填写原因 → 保存 → 返回分类表并更新版本。

SKU 分支：切换 SKU 例外 → 搜索/分类筛选 → `CommissionRules/Edit-SKU` → 设置例外比例、明确 0% 或恢复继承 → 保存并更新预计单件佣金。

### Flow H · 提现审核与打款

`Withdrawals/List` → 审核 → `Withdrawals/Review-Modal` → 通过（影响预览 + 确认，无原因）→ 待打款 → `Withdrawals/Payment-Modal` → 提供凭证 → 标记已打款（不可回退预览 + 确认，无原因）。拒绝分支另要求原因。

敏感查看分支：`Withdrawals/List[APPROVED]` → `Withdrawals/Bank-Reveal` → 本人 TOTP → 60 秒单次展示与一次性复制；失败 5 次进入 Locked，离页立即恢复掩码。

### Flow I · 内容、库存与系统治理

内容分支：`Brands/List`、`Categories/List`、`Banners/List` 分别完成品牌档案、分类保护和广告位启停。

库存分支：`Inventory/List` → 选择 SKU → 查看可售/预占/售后占用 → 调整或查看流水。

治理分支：高风险操作 → `Common/High-Risk-Confirm` → 按操作矩阵填写原因/凭证/TOTP + 影响 + 确认 → `AuditLogs/List`；版本冲突进入 `States/409`。

交互动效：页面切换使用 Instant；Modal、Drawer、Toast 使用 Smart Animate 180ms Ease Out。遵从系统“减少动态效果”时改为 Instant。

| 区域 | 1440 | 1024 |
| --- | --- | --- |
| 侧栏 | 224，图标+文字 | 72，仅图标；点击菜单后以 224 覆盖展开 |
| 内容边距 | 28 | 16 |
| 指标卡 | 4 列 | 2 列 |
| 看板图表 | 趋势 1.7fr / 排行 0.8fr | 趋势 1.35fr / 排行 0.75fr |
| 编辑页 | 主区 + 260 侧栏 | 主区 + 230 侧栏 |
| 表格 | 全字段 | 隐藏 Optional 字段，保持横向可滚动兜底 |
